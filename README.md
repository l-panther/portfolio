# Developer Portfolio

## Description
This project is a personal developer portfolio built using Astro. It showcases projects, technical skills, and experience, providing a central platform for presenting work and professional information.

## Features
- Project showcase with descriptions and links  
- Responsive and accessible user interface  
- Fast performance using Astro static site generation  
- Clean and maintainable code structure  

## Installation
To run the project locally:

```bash
git clone <repository-url>
cd <project-folder>
npm install
npm run dev
```

## Usage
- Access the development server at `http://localhost:3000`  
- Navigate through the site to view projects and content  
- Build the project for production:

```bash
npm run build
```

## Configuration
No additional configuration is required. Content can be updated within the source files.
